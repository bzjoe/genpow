How It Works & Standalone Program Architecture

Cost Formula: $/Watt = Retail Price ($) ÷ Power Output (Watts)

Self-Contained Program File: Every generator record, edit, addition, and selection state is permanently hardcoded directly into the script source code of this file upon export. Opening any exported file gives you an independent, fully updated version with all records permanently baked in.

About "Export Updated Generator File"

How to save new generators and edits: Whenever you add a new generator, edit an existing one, delete an item, or select/deselect models, those changes are stored in your active session. Clicking Export Updated Generator File rewrites the entire standalone HTML program code, embedding your exact current dataset directly into the script baseline.

Smart Filename Preservation: The exported file automatically adopts your exact original filename prefix (preserving underscores and casing) followed by a timestamp (YYMMDD_HHMMSS) to maintain your exact naming convention.
